1. В Git ветка — это по сути лёгкий указатель на коммит, поэтому создаётся почти мгновенно. В SVN ветвление обычно означает копирование структуры каталогов на сервере, поэтому операция тяжелее.

2. Нет. SVN — централизованная система: коммит должен сразу попасть в центральный репозиторий, поэтому без связи с сервером закоммитить нельзя.

3. SVN может быть удобнее, когда:

* нужен строгий централизованный контроль;
* разработчики должны видеть только отдельные папки репозитория;
* проект содержит много больших бинарных файлов;
* команда уже давно использует SVN и переход на Git не окупается.
